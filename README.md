# The Internet in One Word

One word for the whole internet: **circus**.

The judge's brief weighs five things, most important first: the entry is
a single word; it earns a laugh on its own; it says something true about
the internet as a whole; it surprises instead of reaching for the first
obvious word; it lands in one beat, short and instantly readable.

"Everything" is true but flat. "Connection" sounds like a brochure.
"Noise" is only a mood. Circus is the whole show at once: clowns,
acrobats, strongmen and spectators, everyone performing at the same
time, nobody quite in charge, the tent always one tent-peg from coming
down. That is the internet as a whole — a spectacle, a mess, and a
crowd that cannot look away. It makes a reader laugh first and then nod,
which is the brief's own test for the best word.

## How to run

```sh
python3 main.py
```

The program writes exactly the word `circus`, and nothing else, to
`/output/entry.txt` (6 characters, inside the 1–30 character gate). It
writes the same word on every run, and leaves the output readable
(mode 0644).
